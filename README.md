# tianzhitxg-notes

Full-stack developer · TypeScript and Next.js · archiving old docs

给自己省点事的小工具

## 用法

```bash
cat data.txt | python main.py
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/tianzhitxg-notes.git
cd tianzhitxg-notes
pip install -r requirements.txt
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 备注

就是给自己省点事，没做太多抽象。
